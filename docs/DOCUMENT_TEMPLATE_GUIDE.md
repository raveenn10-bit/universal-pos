# Harsh Apex Universal POS - Document Template & PDF Guide

## 1. Supported Document Formats
Harsh Apex Universal POS includes a 100% offline, vector-accurate PDF generation engine powered by PDFKit:
- **80mm Thermal Receipt**: Standard point-of-sale receipt with store header, itemized lines, discounts, tenders, offline verification QR code, and return policy footer.
- **58mm Thermal Receipt**: Compact receipt format for mobile or portable thermal printers.
- **A4 Commercial Tax Invoice**: Full-page multi-page invoice with company tax registration header, customer billing box, alternating row shading, repeated table headers on page breaks, page numbers (`Page X of Y`), and authorized signature line.
- **A4 Customer Statement**: Chronological running balance statement of invoices and settlements.

---

## 2. Shop Owner Template Customizer
Accessed via the **Document Editor** tab in the sidebar:
- **Branding**: Customize Store Name, Tagline, Address, Phone, Email, and Tax TIN.
- **Accent Color**: Brand highlight color applied to table banners, badges, and totals.
- **Typography**: Select from bundled system fonts (Helvetica, Times, Courier) with safe font sizing.
- **Footer Text & Warranty**: Edit exchange policies, warranty terms, and gratitude messages.
- **Column Visibility**: Toggle item codes, discounts, and tax columns.
- **Real-Time Interactive Preview**: Live layout preview before publishing.
- **Published Versioning**: Saving updates the active template version. Previously issued invoices retain their original template snapshot to ensure historical documents never change retroactively.
